# Code of conduct

We are committed to a respectful, harassment-free community.

Be constructive, assume good intent while evaluating evidence, respect privacy,
and avoid publishing another person's memory data, credentials, or identifying
information. Harassment, discrimination, threats, and repeated disruptive
behavior are not acceptable.

Project maintainers may edit or remove contributions and interactions that
violate these expectations. Report conduct concerns privately through the
repository owner's GitHub profile. Maintainers will review reports fairly and
protect reporter privacy where possible.
